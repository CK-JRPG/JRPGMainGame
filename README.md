# JRPGMainGame
청강문화산업대학교 졸업 작품으로 제작한 Unreal Engine 기반 JRPG 메인 게임 프로젝트입니다. <br/>
현재 저장소는 당시 구현된 게임 시스템, 콘텐츠, 프레임워크 구조를 보존하기 위한 목적으로 관리됩니다.

## 개발 종료 안내
이 프로젝트는 졸업 작품 개발 과정에서 제작되었으나, 2026년 6월 2일 팀 해체로 인해 더 이상 정식 개발이 진행되지 않습니다.<br/>
저장소에는 개발 종료 시점까지 구현된 시스템과 리소스가 포함되어 있으며, 일부 기능은 미완성 상태이거나 테스트용 콘텐츠를 포함할 수 있습니다.

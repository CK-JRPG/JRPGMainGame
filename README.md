# JRPGMainGame
청강문화산업대학교 졸업 작품으로 제작한 Unreal Engine 기반 JRPG 메인 게임 프로젝트입니다. <br/>
현재 저장소는 당시 구현된 게임 시스템, 콘텐츠, 프레임워크 구조를 보존하기 위한 목적으로 관리됩니다.

## 프로젝트 개요
- 프로젝트명: JRPGMainGame
- 장르: JRPG
- 엔진: Unreal Engine 5.7
- 개발 기간: 2026.01.20 - 2026.06.02
- 개발 목적: 청강문화산업대학교 졸업 작품
- 개발 상태: 팀 해체로 인한 개발 종료

## 실행 방법
1. Unreal Engine 5.7이 설치되어 있는지 확인합니다.
2. `JRPG.uproject` 파일을 Unreal Engine으로 엽니다.
3. 필요한 경우 Visual Studio 프로젝트 파일을 재생성합니다.
4. 에디터에서 프로젝트를 빌드한 뒤 실행합니다.

기본 게임 맵은 `/Game/Level/Chapter3-1`로 설정되어 있으며, 에디터 시작 맵은 `/Game/Level/TestLevel`입니다.

## 기술 스택
- Unreal Engine 5.7
- C++
- Unreal Gameplay Framework
- UMG
- Enhanced Input
- Niagara
- Gameplay Tags
- Gameplay Tasks
- Unreal Engine Plugin Module Architecture

## 개발 종료 안내
이 프로젝트는 졸업 작품 개발 과정에서 제작되었으나, 2026년 6월 2일 팀 해체로 인해 더 이상 정식 개발이 진행되지 않습니다.<br/>
저장소에는 개발 종료 시점까지 구현된 시스템과 리소스가 포함되어 있으며, 일부 기능은 미완성 상태이거나 테스트용 콘텐츠를 포함할 수 있습니다.
